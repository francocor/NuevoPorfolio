## Descripción

Portfolio personal diseñado y desarrollado desde cero como una SPA (Single Page Application) moderna, con identidad visual propia, animaciones con propósito y una estructura estratégica orientada a conseguir oportunidades como **Frontend Developer**.

El portfolio no solo muestra proyectos — demuestra criterio visual, atención al detalle y enfoque en la experiencia de usuario aplicado directamente en el código.

## Stack técnico

```
Framework      →  React 18 + Vite 7
Estilos        →  Tailwind CSS 3 + CSS custom properties
Animaciones    →  Framer Motion 11
Iconos         →  Lucide React + React Icons
Fuentes        →  Sora · Inter · JetBrains Mono (Google Fonts)
i18n           →  Context API propio (ES / EN)
Deploy         →  Vercel (recomendado)
```

---

## Características destacadas

- **Dark mode premium** — paleta `#08080E` con acentos `#6C63FF` (índigo) y `#00D4FF` (cyan)
- **Gradient mesh animado** — 3 orbs con CSS keyframes en el hero
- **Animaciones con Framer Motion** — stagger de entrada, scroll reveals con `whileInView`, hover physics
- **Casos de estudio** — proyectos presentados con contexto, desafío, rol y decisiones de UX/UI
- **Bilingüe** — sistema de i18n propio con persistencia en localStorage (ES / EN)
- **Responsive** — mobile-first, breakpoints md/lg
- **Dropdown de contacto** — WhatsApp + Gmail con AnimatePresence

## Instalación local

```bash
# Clonar el repositorio
git clone https://github.com/francocor/NuevoPorfolio.git
cd NuevoPorfolio

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build
```
